# مدیریت مش

سامانه مدیریت مشتریان، پرداخت‌ها (یک‌جا / چندمرحله‌ای / اقساطی) و پشتیبانی — PHP 8.1 خام (MVC سبک + PDO)، MySQL، Bootstrap 5 RTL، دارک‌مود، تاریخ شمسی.

## نصب (روش پیشنهادی: نصب‌کننده خودکار)

1. پوشه پروژه را داخل `www` لاراگون (یا ریشه وب‌سرور) قرار دهید؛ مثلاً `C:\laragon\www\mesh-client-management`.
2. آدرس پروژه را در مرورگر باز کنید (مثلاً `http://localhost/mesh-client-management`). چون هنوز نصب نشده، خودکار به `install/` می‌روید.
3. آدرس سرور، نام دیتابیس، نام کاربری و رمز MySQL را وارد کنید (لاراگون: `127.0.0.1` / `root` / رمز خالی)، سپس نام و رمز مدیر کل را بسازید و «نصب برنامه» را بزنید.

نصب‌کننده دیتابیس را می‌سازد، جدول‌ها را وارد می‌کند، مدیر کل را ثبت می‌کند و `config/config.php` را می‌نویسد. بعد از آن صفحه نصب قفل می‌شود. برای نصب مجدد، فایل `config/config.php` را پاک کنید.

### نصب دستی (جایگزین)

phpMyAdmin → **Import** → `database/schema.sql`، سپس `config/config.sample.php` را به `config/config.php` کپی و اطلاعات دیتابیس را ویرایش کنید. ورود پیش‌فرض این روش: **admin** / **admin123** (حتماً تغییر دهید).

### ارتقا از نسخه قبلی

فایل‌های `database/migrations/` را به ترتیب روی دیتابیس موجود اجرا کنید (مثلاً `002_internal_tickets.sql` برای تیکت داخلی).

## ساختار

```
index.php            ← Front Controller  (index.php?r=controller/action)
install/             ← نصب‌کننده (قفل بعد از نصب)
config/config.php    ← تنظیمات دیتابیس و آپلود (توسط نصب‌کننده ساخته می‌شود؛ در گیت نیست)
app/core/            ← Router, DB(PDO), Auth, Jalali, Upload, Notifier, Xlsx, helpers
app/controllers/     ← Dashboard, Customers, Projects, Finance, Support, Categories, Reports, Admins, Settings, Files, Notifications
app/models/          ← Project, Category, Report
app/views/           ← قالب‌ها (همه فرم‌ها داخل مودال و با AJAX)
assets/              ← CSS/JS + کتابخانه‌ها به‌صورت لوکال (بدون نیاز به اینترنت)
storage/uploads/     ← پیوست‌ها (خصوصی؛ فقط از مسیر files/view با بررسی دسترسی)
database/schema.sql  ← اسکیمای دیتابیس
```

## نکات

- **تاریخ‌ها**: همه ورودی‌ها و نمایش‌ها شمسی است؛ در دیتابیس برای دقت روزشمار و گزارش‌ها به‌صورت DATE استاندارد ذخیره می‌شود.
- **نوتیفیکیشن**: بدون Cron؛ هر بار پنل باز شود (حداکثر هر ۱۰ دقیقه) سررسیدهای ۷ روز آینده، معوقه‌ها و پایان پشتیبانی‌ها بررسی می‌شوند. تعداد روز از «تنظیمات» قابل تغییر است.
- **دسترسی‌ها**: مدیر کل همه‌چیز را دارد؛ برای ادمین‌های دیگر هر بخش (مشتریان، پروژه‌ها، مالی، پشتیبانی، گزارش‌ها، دسته‌بندی‌ها) در سه سطح «بدون دسترسی / مشاهده / مدیریت» تنظیم می‌شود.
- **سود خالص** = دریافتی‌ها + تمدیدهای پرداخت‌شده − هزینه‌ها و ابزارهای ثبت‌شده برای پروژه.
- **خروجی Excel**: فایل xlsx واقعی (راست‌به‌چپ، ۵ شیت). اگر افزونه `zip` در PHP خاموش باشد CSV داده می‌شود.
- **خروجی PDF**: نسخه چاپی گزارش باز می‌شود؛ در پنجره چاپ گزینه «Save as PDF» را بزنید (فونت فارسی کامل حفظ می‌شود).
- **امنیت**: PDO با Prepared Statement، CSRF روی همه فرم‌ها، `password_hash`، قفل ۵ دقیقه‌ای بعد از ۵ ورود ناموفق، بررسی نوع واقعی فایل (MIME) و نام تصادفی برای آپلودها، `.htaccess` برای بستن پوشه‌های حساس.
- روی سرور واقعی در `config/config.php` مقدار `debug` را `false` کنید و ترجیحاً `storage_path` را به پوشه‌ای بیرون از `www` ببرید.
